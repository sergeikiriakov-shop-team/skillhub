# SkillHub — инструкция для разработчиков

SkillHub — общий реестр скиллов Claude Code для команды: единое место, где скиллы хранятся,
оцениваются по одной рубрике, ищутся по смыслу и откуда их можно ставить себе в Claude Code.
Сам сервис **не вызывает LLM** — вся «умная» работа (оценка, категоризация, синтез) делается вашим
Claude Code и присылается обратно.

- **Адрес:** https://166.1.29.218.sslip.io
- **Для просмотра нужен вход через GitHub** (на этом сервере каталог/поиск/рейтинги закрыты для
  неавторизованных). **Запись** (загрузка/оценка скиллов) — дополнительно требует роль.

## 1. Вход на портал

Откройте https://166.1.29.218.sslip.io и нажмите **«Sign in with GitHub»** (справа вверху).
Подойдёт любой GitHub-аккаунт. Без входа виден только экран входа. После входа вы — **viewer**
(смотрите каталог). Чтобы получить право загружать/оценивать, попросите администратора повысить
роль: `viewer → contributor` (может загружать) `→ evaluator` (может отправлять оценки).

Язык интерфейса переключается тумблером **EN / RU** в шапке. Раздел **Guide** на портале дублирует
эту инструкцию и всегда показывает актуальные команды.

## 2. Подключение SkillHub к своему Claude Code (MCP)

MCP работает **на сервере** — ни Docker, ни образа, ни токена не нужно.

**Проще всего — попросить свой Claude Code обычным текстом** (если установлен скилл
`connect-skillhub`):

> установи SkillHub MCP для https://166.1.29.218.sslip.io

**Или выполнить одной командой** в терминале:

```bash
claude mcp add --transport http --scope user skillhub https://166.1.29.218.sslip.io/mcp
```

- `--transport http` — это удалённый MCP по URL (как `beliani-*`), а не локальный процесс.
- `--scope user` — MCP становится доступен во всех ваших проектах (используйте `--scope project`,
  чтобы записать его в `.mcp.json` конкретного репозитория для всей команды).
- **Перезапустите Claude Code**, затем проверьте: `claude mcp list` — должен появиться `skillhub`
  (может писать «Needs authentication» до первого входа — это нормально).

### Авторизация MCP (вход через браузер, один раз)

При **первом** вызове инструмента SkillHub Claude Code сам откроет браузер для однократного входа
через **GitHub (OAuth)** — подтвердите, и вы подключены. Копировать/вставлять токен не нужно (им
управляет Claude Code). Если инстанс закрывает и чтение, вход спросят уже при первом просмотре.

Доступ зависит от роли: свежий аккаунт может читать и загружать скилы; оценивание (`evaluator`) и
управление пользователями (`admin`) выдаёт админ.

## 3. Что можно делать (просто говорите Claude Code)

- **Найти скилл:** «что есть в SkillHub про SQL?» → семантический поиск.
- **Загрузить скилл:** «импортируй этот SKILL.md в SkillHub».
  - Реестр хранит **одну запись на имя**: повторная загрузка того же имени создаёт новую **версию**,
    а не копию. Авторство берётся из вашего GitHub-аккаунта (подделать нельзя).
  - Загрузка контента, **идентичного** существующему скиллу под другим именем, отклоняется (409);
    просто **похожий** — принимается с предупреждением.
- **Оценить скиллы** (роль evaluator): «оцени неоценённые скиллы в SkillHub» — Claude Code возьмёт
  очередь, загрузит общую рубрику и проставит оценки по единому алгоритму.
- **Установить скилл из реестра себе:** «установи скилл `<имя>` из SkillHub в мой проект» — Claude
  Code запишет `SKILL.md` (и references) в `.claude/skills/<имя>/`.
- **Рекомендации** и **методология оценки** — на портале в соответствующих разделах.

## Проблемы

- `claude mcp list` не показывает `skillhub` → перезапустите Claude Code; проверьте, что Docker
  запущен.
- Не тянется образ (`denied`) → образ должен быть публичным в GHCR (это к админу).
- Вход не проходит / «Invalid OAuth state» → открывайте портал строго по адресу
  `https://166.1.29.218.sslip.io` (не по IP/другому имени) и не держите страницу логина открытой
  дольше ~10 минут.
